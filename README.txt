# PT. BHUMI GLOBAL NUSANTARA

## Struktur folder

```text
bhumi-global-nusantara/
│
├── index.html
├── style.css
├── script.js
│
└── images/
    ├── logo.png
    ├── hero.png
    ├── tentang_kami.jpg
    ├── topografi.png
    ├── drone.png
    ├── lidar.png
    ├── bathymetry.png
    ├── bm-cp.png
    ├── batas-lahan.png
    ├── tambang.png
    └── jalan.png
```

## Cara menjalankan

1. Buat folder `images` di samping `index.html`.
2. Masukkan semua foto yang sudah kamu punya ke folder `images`.
3. Pastikan nama file sama persis dengan daftar di atas.
4. Buka `index.html` di browser.

Website sudah dibuat responsive untuk desktop, tablet, dan HP.
Menu HP menggunakan hamburger menu, gambar otomatis menyesuaikan ukuran,
dan form kontak otomatis membuka WhatsApp.
